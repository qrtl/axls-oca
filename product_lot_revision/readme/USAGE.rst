To use this module, you need to:


#. Go to Inventory > Operations > Lot/Serial Numbers
#. Open a lot/serial number form
#. You will see a "Revision" field and buttons to view, create, or assign a revision
#. Click "Assign Revision" to assign an existing revision to the lot/serial number
#. Click "Create Revision" to create a new revision for the product and assign it to the lot/serial number
#. Click "View Revision" to view the details of the assigned revision

When creating a new lot/serial number, the system will automatically assign the current active revision of the product to the lot/serial number.

This module extends the stock quant tree view to display the revision number of lot/serial numbers when they have a revision.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module, you need to:

#. Go to Inventory > Reporting > Inventory Report
#. The revision number will be displayed in a new column after the lot/serial number column when a lot/serial number has a revision
